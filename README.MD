# TANTE CULIK AKU DONG

[LIVE DEMO](https://tante.rhinz.tech)

## Tutorial
- Open the HTML file in your browser
- If the song doesn't play automatically, click the play button at the top of the container
- You can also restart the song by clicking the restart button

## Features
- Lyrics synchronized with audio playback
- Chat-like interface with typing animation
- Progress bar for easy navigation
- Mobile-friendly responsive design
